## 🚀 Projects

### 1. [HackMetrics](https://github.com/archita024/HackMetrics)

A hackathon evaluation platform designed to simplify project judging and result management through a centralized dashboard.

**✨ Features**
- 🔐 Authentication for users.
- 📝 Dedicated judge dashboard for project evaluation.
- 📊 Evaluation data stored and managed using Firebase Firestore.
- 🏆 Results dashboard to view project evaluation outcomes.
- ⚡ Responsive web interface for a smooth user experience.

**💻 Tech Stack:** Next.js • TypeScript • Tailwind CSS • Firebase • Vercel

**🔗 Links:** [GitHub Repository](https://github.com/archita024/HackMetrics) | [Live Website](https://hack-metrics.vercel.app/)
